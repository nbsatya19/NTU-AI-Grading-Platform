## Running locally

Prerequisites: [Node.js](https://nodejs.org) 18.18 or later.

```bash
# from inside the extracted project folder
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in a browser. (If you have [pnpm](https://pnpm.io) installed, `pnpm install && pnpm dev` works too — a `pnpm-lock.yaml` is included.)

## GitHub Pages

The site is built as a static export (`output: "export"`) and deployed by `.github/workflows/deploy-pages.yml` on every push to `main`. In the repo, set **Settings → Pages → Source** to **GitHub Actions**.
